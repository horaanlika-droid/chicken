# ДРУЖБЫ, 18, КВ. 14

Одностраничный интерактивный storyboard / режиссёрский treatment для вертикального stop-motion короткого метра.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер из корня проекта:

```sh
python3 -m http.server 4173 --bind 0.0.0.0
```

## В проекте

- Семь сцен с таймингом, визуальными указаниями, закадровым внутренним монологом и звуковыми акцентами.
- Интерактивная раскадровка: воспроизведение 80-секундного таймлайна, переход к сцене, пауза и сброс.
- Адаптивная вёрстка для вертикальных экранов и клавиатурная навигация по сценам.
- Иллюстративные миниатюрные кадры сверстаны в CSS; постерное изображение — `assets/stairwell-hero.jpg`.
